# R-Squared ($R^2$) Overview

## What It Is
R-Squared ($R^2$), also known as the **Coefficient of Determination**, is a statistical metric that measures the goodness-of-fit for regression models. It determines the proportion of variance in the dependent target variable ($y$) that can be explained by the independent predictor features ($x$) in the model.

## The Mathematical Foundation
The calculation compares your model's errors against a basic baseline model (which simply predicts the average value of $y$ for every observation).

$$R^2 = 1 - \frac{SS_{\text{res}}}{SS_{\text{tot}}}$$

### Component Breakdown:
1.  **$SS_{\text{res}}$ (Sum of Squared Residuals):** The total squared error of your actual model.
    $$SS_{\text{res}} = \sum_{i=1}^{n} (y_i - \hat{y}_i)^2$$
2.  **$SS_{\text{tot}}$ (Total Sum of Squares):** The total variance present in the actual data relative to the mean. This represents the error of the baseline model.
    $$SS_{\text{tot}} = \sum_{i=1}^{n} (y_i - \bar{y})^2$$

*   **$y_i$**: The actual real-world value for observation $i$.
*   **$\hat{y}_i$**: The predicted value generated by your regression model for observation $i$.
*   **$\bar{y}$**: The mean average value of all actual $y$ data points.

---

# Interpreting R-Squared Values

R-Squared typically ranges from **0 to 1** (or 0% to 100%):

*   **$R^2 = 1.0$ (100%):** Perfect model. The model's predictions match the actual data points perfectly ($SS_{\text{res}} = 0$).
*   **$R^2 = 0.0$ (0%):** The model performs no better than a simple horizontal line drawn at the data's mean average value.
*   **Negative $R^2$:** It is possible to get a negative value if your model fits the data *worse* than a simple mean baseline. This usually means the model choice is fundamentally flawed or a trend line is sloping the wrong way.

---

# The Core Flaw: Artificial Inflation

While a higher $R^2$ score is generally desirable, it possesses a critical mathematical flaw: **it can never decrease when you add new features.**

## Why This Happens
Every time you add a new independent variable to your feature matrix—even if it is completely random noise (like adding a "Coin Flip" column to predict "House Prices")—the optimization engine will find a tiny, accidental correlation. This forces $SS_{\text{res}}$ to shrink slightly or stay the same, which artificially inflates your $R^2$ score.

## The Solution: Adjusted R-Squared
To fix this artificial inflation, you must use **Adjusted R-Squared** when working with multi-variable models. It adds a penalty based on the number of features you introduce:

$$\text{Adjusted } R^2 = 1 - \left[ \frac{(1 - R^2)(n - 1)}{n - p - 1} \right]$$

*   **$n$**: The total sample size (number of data observations).
*   **$p$**: The number of independent predictor features in the model.

### The Behavior:
*   If you add a **useful feature**, the improvement in $R^2$ outweighs the penalty, and Adjusted $R^2$ **increases**.
*   If you add a **useless feature**, the penalty outweighs any accidental correlation, and Adjusted $R^2$ **decreases**.

---

# Feature Scaling Requirement

Feature scaling (like Standardization or Normalization) is **not required** to calculate $R^2$. Because the formula relies on relative variance proportions ($SS_{\text{res}} / SS_{\text{tot}}$), the scale units in the numerator and denominator completely cancel each other out.

# Adjusted R-Squared Overview

## What It Is
Adjusted R-Squared is a modified version of the standard R-Squared ($R^2$) metric designed specifically for multiple regression models. It measures the proportion of variance in the dependent target variable ($y$) explained by your features, while automatically penalizing the model for adding extra independent variables ($x$) that add no real predictive value.

---

## The Core Problem with Standard R-Squared
Standard R-Squared has a mathematical flaw: **it is a non-decreasing metric**. 

Every time you add a new independent variable to a model—even if it is completely random noise (such as adding a "Coin Flip Result" column to predict "House Prices")—the optimization engine will find a tiny, accidental correlation in the training data. This causes the standard $R^2$ score to artificially freeze or increase, giving a false impression that the model is improving when it is actually just overfitting.

---

## The Mathematical Foundation
Adjusted R-Squared solves this flaw by incorporating both the sample size ($n$) and the total number of predictors ($p$) directly into its formula:

$$\text{Adjusted } R^2 = 1 - \left[ \frac{(1 - R^2)(n - 1)}{n - p - 1} \right]$$

### Component Breakdown:
*   **$R^2$**: The standard Coefficient of Determination.
*   **$n$**: The total sample size (the number of data rows/observations).
*   **$p$**: The number of independent predictor features used as inputs (excluding the intercept).
*   **$n - p - 1$**: The degrees of freedom left for the residual errors.

---

## How It Behaves: The Reward and Penalty System

Adjusted R-Squared acts like an honest judge that balances model complexity against predictive power:

1.  **Adding a Useful Feature:** If you add a feature that strongly correlates with the target, the increase in the standard $R^2$ value will outweigh the penalty introduced by increasing $p$. As a result, the **Adjusted $R^2$ increases**.
2.  **Adding a Useless Feature:** If you add a feature that contains mostly random noise, the standard $R^2$ will barely move, but the penalty term will grow because $p$ increased. As a result, the **Adjusted $R^2$ decreases**.

Unlike standard R-Squared, Adjusted R-Squared can theoretically become **negative** if a model is highly complex ($p$ is large) but performs worse than a simple horizontal line drawn at the data's mean average.

---

## Comparison Matrix: $R^2$ vs. Adjusted $R^2$


| Structural Dimension | Standard R-Squared ($R^2$) | Adjusted R-Squared |
| :--- | :--- | :--- |
| **Primary Focus** | Measures overall goodness-of-fit. | Measures goodness-of-fit while tracking complexity. |
| **Feature Addition** | Always increases or stays the same. | Can increase, decrease, or stay the same. |
| **Best Used For** | Simple Linear Regression (1 feature). | Multiple Linear Regression ($>1$ feature). |
| **Overfitting Alert** | Blind to overfitting caused by redundant features. | Flags overfitting when it begins to drop below the standard $R^2$. |

# Ordinary Least Squares (OLS) Overview

## What It Is
Ordinary Least Squares (OLS) is a foundational optimization method used to find the best-fitting straight line through a set of data points in linear regression models. It is an algebraic, closed-form solution, meaning it solves for the optimal line mathematically in a single deterministic step without needing iterative approximations.

## The Architectural Goal: Minimizing the Squares
The "Best-Fitting Line" is defined as the line that minimizes the total distance between your actual data points and the model's predicted line. 

OLS specifically targets the **Sum of Squared Residuals (SSR)**:

$$\text{SSR} = \sum_{i=1}^{n} (y_i - \hat{y}_i)^2$$

*   **$y_i$**: The actual real-world value for observation $i$.
*   **$\hat{y}_i$**: The predicted value generated by your line ($\beta_0 + \beta_1x_i$).
*   **The Residual ($y_i - \hat{y}_i$):** The vertical distance or error gap between the actual point and the line.

### Why Square the Residuals?
1.  **Canceling Negatives:** Points below the line have negative residuals, while points above have positive ones. Squaring them ensures they do not cancel each other out when summed.
2.  **Penalizing Large Errors:** Squaring an error gives disproportionately heavier penalties to severe mispredictions (e.g., an error of 4 becomes a penalty of 16), forcing the line to stay close to outliers.

---

## The Mathematical Formulas

### Simple Linear Regression (1 Feature)
For a single independent variable, calculus is used to find where the derivative of the error function equals zero, yielding these direct equations:

$$\beta_1 = \frac{\sum_{i=1}^{n} (x_i - \bar{x})(y_i - \bar{y})}{\sum_{i=1}^{n} (x_i - \bar{x})^2} = \frac{\text{Covariance}(x, y)}{\text{Variance}(x)}$$

$$\beta_0 = \bar{y} - \beta_1\bar{x}$$

### Multiple Linear Regression (Matrix Form)
When using multiple features, OLS uses linear algebra matrices to compute all coefficients ($\beta$) simultaneously in one calculation:

$$\hat{\beta} = (X^TX)^{-1}X^Ty$$

*   **$X$**: The matrix of independent input features (with an added column of 1s for the intercept).
*   **$X^T$**: The transposed feature matrix.
*   **$(X^TX)^{-1}$**: The inverse matrix, which acts like matrix division.
*   **$y$**: The vector of actual target outputs.

---

## Core Assumptions
For OLS to provide the most reliable, unbiased estimates (known historically as the BLUE: Best Linear Unbiased Estimator), the data must meet these criteria:
1.  **Linearity:** The true relationship between features and targets is linear.
2.  **No Multicollinearity:** The $X$ variables must not be perfectly correlated, otherwise the matrix $(X^TX)$ becomes singular and cannot be inverted.
3.  **Homoscedasticity:** The residual variance must remain constant across all levels of predictions.
4.  **Exogeneity:** The residual errors must have a mean of zero and must be uncorrelated with the independent variables $X$.

---

## Feature Scaling in OLS

Feature scaling is **not required** for OLS linear regression models.

### The Core Reason: Analytical Invariance
Because the OLS matrix equation computes the exact mathematical inverse of the feature scales, the weights adjust automatically. If you multiply a feature column by 1,000, its calculated coefficient ($\beta$) will automatically divide by 1,000 during the matrix multiplication. The final predicted values ($\hat{y}$) and error boundaries remain completely unchanged.

# Residual Errors ($\epsilon$) Overview

## What They Are
A **Residual Error** (often simply called a **residual** or **error term**) is the exact mathematical difference between an actual observed real-world value and the predicted value generated by your machine learning model. It represents the portion of the target variable that your model failed to explain, capture, or understand.

---

## The Mathematical Equation

For any single observation $i$ in your dataset, the residual ($e_i$) is calculated as:

$$e_i = y_i - \hat{y}_i$$

*   **$y_i$**: The true, actual real-world value observed in your data partition (e.g., An actual house selling for \$500,000).
*   **$\hat{y}_i$**: The predicted value output by your regression model equation (e.g., Your model estimated the house would sell for \$480,000).
*   **$e_i$**: The resulting residual error ($\$500,000 - \$480,000 = \$20,000$).

---

## Visual Interpretation

In a geometric space, if you visualize your regression model as a line or curve cutting through a cloud of scatter points, the residuals are the **vertical lines** connecting the actual data points to your model's line.

# $R^2$ Score Scale Selection and Interpretation

## The Core Concept
The $R^2$ score is a **dimensionless metric**, meaning it scales relative proportions rather than absolute data units. Because of this mathematical structure, **$R^2$ scores remain identical regardless of whether you scale your variables or keep them in their raw forms.**

---

# Why Scale Selection Does Not Change $R^2$

The mathematical formula for $R^2$ is defined by the ratio of error variances:

$$R^2 = 1 - \frac{\sum (y_i - \hat{y}_i)^2}{\sum (y_i - \bar{y})^2}$$

When you apply a linear feature scaling method—such as **Standardization (Z-score)** or **Normalization (Min-Max)**—to your data:
* **The Intercept and Coefficients Change:** The model adapts its weights ($\beta$) to compensate for the shifted numerical ranges.
* **The Predictions Scale Proportionally:** The distance between the actual target ($y_i$) and the predicted value ($\hat{y}_i$) shrinks or expands by the exact same scaling factor as the global data variance ($\bar{y}$).
* **The Scale Cancels Out:** Because the scale factor applies equally to both the numerator (residuals) and the denominator (total variance), the units mathematically cancel out. Your final $R^2$ score stays exactly the same.

---

# Exception: When Scale Selection Alters $R^2$

There are specific scenarios where feature scaling choices **will** indirectly change your final $R^2$ score:

### 1. Distance-Based Algorithms (SVR, KNN)
If you do not scale your independent features ($X$) before running an algorithm like **Support Vector Regression (SVR)**, the model's distance metrics will be warped. Large-scale features will completely overpower small-scale features, leading to a poorly fit model and a drastically lower $R^2$ score.

### 2. Regularized Regression (Ridge, Lasso, ElasticNet)
Regularization penalizes the size of the model coefficients. If your features are unscaled, the penalty will be applied unfairly to features with smaller units. Scaling ensures an even playing field, allowing the optimization engine to find the true pattern and maximize your Adjusted $R^2$.

### 3. Non-Linear Label Transformations ($\log(y)$, $\sqrt{y}$)
If you scale your target variable using a **non-linear transformation** (like taking the natural log of salary: `np.log(y)`), you are changing the underlying distribution of your data. This modifies the spatial relationships between points, which **will change your $R^2$ score**. 

*Note: If you transform your target variable during training, you must inverse-transform your predictions back to the original scale before calculating the final metrics for a fair comparison.*
