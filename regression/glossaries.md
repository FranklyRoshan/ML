 # Core Machine Learning Terminology Glossary

## 1. Concept & Mechanics
*   **Intuition**: The foundational logic and real-world behavior of an algorithm, focusing on *how* and *why* it works conceptually rather than using mathematical proofs.
*   **Feature (Independent Variable / $x$)**: An input variable or measurable property used by the model to learn patterns and make predictions (e.g., Square Footage, Age).
*   **Target (Dependent Variable / $y$)**: The final output or label that the model is trying to predict (e.g., House Price, Customer Churn).
*   **Observation (Sample / Data Point)**: A single row in a dataset containing a unique instance of features and its corresponding target value.

## 2. Model Architecture
*   **Hyperplane**: A decision boundary that splits data space into distinct classes or maps a regression line. It is a straight line in 2D space, a flat plane in 3D, and a hyperplane in higher dimensions.
*   **Intercept ($\beta_0$ or Bias $b$)**: The baseline value predicted by the model when all input feature values are set to exactly zero.
*   **Coefficient ($\beta_n$ or Weight $w_n$)**: The multiplier assigned to a feature that dictates how much influence that specific variable has on the final prediction.
*   **Residual (Error / $\epsilon$)**: The vertical distance between the actual real-world data point and the prediction line generated by the model ($y_{\text{actual}} - y_{\text{predicted}}$).
*   **Kernel**: A mathematical function used to transform low-dimensional, non-linear data into a higher-dimensional space so a linear model can solve it.

## 3. Preprocessing & Data Transformation
*   **Feature Scaling**: Transforming the numerical ranges of input features so they all sit on a uniform scale, preventing large numbers from dominating distance calculations.
*   **Standardization (Z-score Normalization)**: Rescaling data so it has a mean ($\mu$) of `0` and a standard deviation ($\sigma$) of `1`.
*   **Normalization (Min-Max Scaling)**: Shifting and squeezing data scales so every value falls strictly within a fixed range, typically between `0` and `1`.
*   **Imputation**: The statistical process of replacing missing or null data fields with substituted values (e.g., column mean, median, or mode) to prevent data loss.

## 4. Model Training & Pitfalls
*   **Ordinary Least Squares (OLS)**: An algebraic, closed-form optimization strategy that fits a regression line by minimizing the sum of the squared residual errors.
*   **Gradient Descent**: An iterative optimization algorithm that takes small, calculated steps downward toward the lowest point of an error curve to find optimal weights.
*   **Overfitting**: A flaw where a model learns training data noise too perfectly, resulting in excellent training scores but failing to generalize to new, unseen data.
*   **Underfitting**: A flaw where a model is too simple to capture the underlying pattern of the data, resulting in poor performance on both training and test sets.
*   **Multicollinearity**: A problematic scenario where two or more independent features are highly correlated with each other, destabilizing coefficient weights.

## 5. Model Evaluation
*   **$R^2$ Score (Coefficient of Determination)**: A metric ranging from `0` to `1` that indicates the percentage of variance in the target variable explained by the features.
*   **RMSE (Root Mean Squared Error)**: The average distance between predicted values and actual values, measured in the exact same units as the target variable.
